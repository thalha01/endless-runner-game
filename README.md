# 🏃‍♂️ Super Endless Runner Game

A dynamic 2D Endless Runner browser game built using HTML5 Canvas, Vanilla JavaScript, and CSS. Players dodge obstacles, perform double jumps, collect coins, and activate powerful power-ups while chasing their highest score.

---

## ✨ Features

- **🎮 Dynamic Gameplay:** Smooth physics-based running and double-jump mechanics.
- **🛡️ Power-ups:**
  - **Shield (Blue):** Protects the player from one collision obstacle.
  - **Magnet (Pink):** Automatically pulls nearby gold coins toward the player.
- **🪙 Coin System & Score Boost:** Collecting gold coins adds bonus score (+50 pts) to break high records faster.
- **💾 Local Storage Persistence:** Automatically saves your **High Score** and **Max Coins** across browser sessions.
- **🔊 Web Audio API Sound Effects:** Procedurally generated sound effects for jumps, coin pickups, power-ups, and game over (no external audio files required).
- **🎨 Visuals & Animations:** Parallax background clouds, dust particle effects on jump, and character running animations.

---

## 🕹️ How to Play

1. Open `index.html` in any modern web browser.
2. Use controls to navigate the runner:
   - **Spacebar / Up Arrow / W / Left Mouse Click:** Jump / Double Jump.
3. Dodge red obstacles to stay alive.
4. Collect gold coins and power-ups to maximize your score.

---

## 🛠️ Tech Stack

- **HTML5 Canvas:** Game rendering and layout structure.
- **CSS3:** Styling and UI layout.
- **JavaScript (ES6):** Game loop, physics engine, collision detection, and Web Audio API.
